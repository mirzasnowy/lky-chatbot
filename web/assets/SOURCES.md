# Image sources

All images are local files in this folder (no hotlinking). Every image is
freely licensed; the file page, author and license for each are below.
Colour photos are shown black-and-white with a CSS `grayscale` filter,
except the portrait, which is black-and-white in the original.

## portrait.jpg — Lee Kuan Yew, 1982

- File page: https://commons.wikimedia.org/wiki/File:Lee_Kuan_Yew,_1982.tif
- What it is: half-length portrait of Lee Kuan Yew, seated, facing front,
  during an interview on 22 July 1982 (United States Library of Congress).
- License: Public domain.
- Local file: a 960 px JPEG thumbnail of the original TIFF, cropped to
  remove the film-frame sprocket border (865 x 1342).

## portrait-avatar.jpg — square crop of the portrait

- Same source and license as portrait.jpg. A 256 x 256 crop of the face,
  made locally with PIL. Used as the assistant avatar in chat bubbles.

## signature.svg — Lee Kuan Yew's signature

- File page: https://en.wikipedia.org/wiki/File:Lee_Kuan_Yew_signature.svg
- License: Public domain (PD, signature below the threshold of
  originality). The file lives on English Wikipedia, not Commons.
- Local file: the original SVG, unchanged.
